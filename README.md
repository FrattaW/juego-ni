# El Juego del Ñi

Carpeta lista para publicar como web app.

## Opcion recomendada

Subir esta carpeta a GitHub Pages o a tu propia web. El archivo principal debe quedar como `index.html`.

## Como lo instalan los niños

En iPhone:

1. Abrir el link en Safari.
2. Tocar Compartir.
3. Elegir Agregar a pantalla de inicio.

En Android:

1. Abrir el link en Chrome.
2. Tocar Instalar si aparece.
3. Si no aparece, abrir el menu y elegir Agregar a pantalla principal.

## Archivos importantes

- `index.html`: el juego.
- `manifest.webmanifest`: datos de la app instalada.
- `sw.js`: cache offline basico.
- `icons/`: iconos para pantalla de inicio.
